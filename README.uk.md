# Boosteroid Tweaks 🚀

[🇬🇧 English](README.md) | [🇷🇺 Русский](README.ru.md) | [🇺🇦 Українська](README.uk.md) | [🇪🇸 Español](README.es.md)

Boosteroid Tweaks — це потужний користувацький скрипт (Userscript), який значно покращує ваш досвід використання хмарного ігрового сервісу [Boosteroid](https://cloud.boosteroid.com/). 

Скрипт додає можливості для управління серверами, надійний захист від розриву з'єднання через неактивність (Anti-AFK), а також зручний оверлей зі статистикою сесії.

## ✨ Переваги та основні функції

*   **🛡️ Невидимий Anti-AFK (Захист від відключення)**
    Забудьте про попередження "Ви все ще тут?" та 10-хвилинний тайм-аут. Скрипт перехоплює запити активності від Boosteroid прямо на рівні мережевого сокета (WebSocket) та миттєво відповідає серверу. Вікно з попередженням навіть не з'являється на екрані! Ідеально підходить для довгих ігрових сесій або використання Steam Remote Play.
*   **🌍 Менеджер серверів (Блокування лагаючих дата-центрів)**
    Потрапляєте на сервер з високим пінгом або поганою якістю? Скрипт автоматично визначає ваш поточний сервер і дозволяє додати його до "чорного списку". Під час наступного запуску гри скрипт заблокує підключення до небажаного сервера, змушуючи Boosteroid перенаправити вас на інший дата-центр.
*   **📊 Просунута статистика (Better Stats)**
    Вбудований оверлей (аналог лічильників FPS в Steam або GeForce Experience), який у реальному часі відображає:
    *   **Ping (мс)** — затримку до сервера
    *   **FPS** — кадрову частоту відеопотоку
    *   **Bitrate** — поточний бітрейт мережі (Мбіт/с)
    *   **Loss** — втрату пакетів (впливає на фрізи)
    *   **Resolution** — реальну роздільну здатність відеопотоку
*   **🎨 Зручний інтерфейс (UI)**
    Налаштування викликаються кліком на іконку шестірні і вбудовані прямо в сторінку Boosteroid з використанням технології Shadow DOM (що гарантує відсутність конфліктів із дизайном самого сайту).
*   **🌐 Багатомовність**
    Підтримка англійської, російської, української та іспанської мов з автоматичним визначенням мови системи.

## ⚙️ Як встановити

Встановлення займає всього пару хвилин:

1. **Встановіть розширення Tampermonkey** для вашого браузера (підтримуються Chrome, Firefox, Edge, Safari, Opera):
   * [Tampermonkey для Chrome](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   * [Tampermonkey для Firefox](https://addons.mozilla.org/ru/firefox/addon/tampermonkey/)
   * [Tampermonkey для Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
   
2. **Встановіть сам скрипт:**
   * Відкрийте розширення Tampermonkey та виберіть **"Створити новий скрипт"** (Create a new script).
   * Видаліть весь вміст у відкритому вікні.
   * Скопіюйте весь код із файлу `boosteroid_tweaks.user.js` в репозиторії та вставте його в редактор Tampermonkey.
   * Натисніть `Ctrl+S` (або Файл -> Зберегти), щоб зберегти скрипт.

3. **Готово!**
   * Перейдіть на сайт [cloud.boosteroid.com](https://cloud.boosteroid.com/).
   * У лівому нижньому кутку екрана (або на сторінці запуску) з'явиться іконка **Boosteroid Tweaks** ⚙️. Натисніть на неї для налаштування!

## 📝 Як користуватися менеджером серверів

1. Запустіть будь-яку гру.
2. Відкрийте панель **Boosteroid Tweaks** (кнопка ⚙️).
3. У розділі **"Останній сервер"** ви побачите адресу дата-центру, до якого ви підключилися (наприклад, `gw-par.boosteroid.com`).
4. Якщо сервер працює погано (великий пінг/втрати пакетів), натисніть кнопку **"Заблокувати цей сервер"**.
5. Завершіть сесію та запустіть гру заново — скрипт заблокує підключення до цієї адреси, і Boosteroid підбере для вас інший дата-центр.

## 👨‍💻 Для розробників

Скрипт використовує передові методи інжекту:
* Перевизначення конструктора `window.WebSocket` для відстеження та фільтрації мережевого обміну з серверами Boosteroid (обхід AFK та блокування).
* Використання WebRTC API (`RTCPeerConnection`) для збору нативної телеметрії без затримок.
