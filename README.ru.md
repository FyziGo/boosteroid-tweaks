# Boosteroid Tweaks 🚀

[🇬🇧 English](README.md) | [🇷🇺 Русский](README.ru.md) | [🇺🇦 Українська](README.uk.md) | [🇪🇸 Español](README.es.md)

Boosteroid Tweaks — это мощный пользовательский скрипт (Userscript), который значительно улучшает ваш опыт использования облачного игрового сервиса [Boosteroid](https://cloud.boosteroid.com/). 

Скрипт добавляет возможности для управления серверами, надежную защиту от разрыва соединения из-за бездействия (Anti-AFK), а также удобный оверлей со статистикой сессии.

## ✨ Преимущества и основные функции

*   **🛡️ Многорежимный Anti-AFK (Защита от отключения)**
    Забудьте о предупреждениях "Вы всё ещё тут?" и 10-минутном тайм-ауте. Поддерживает 3 режима: 'Выкл', 'Сетевой перехват' (мгновенные ответы по сокету без появления окна) и 'Симуляция F15'. Идеально подходит для долгих игровых сессий или Steam Remote Play.
*   **🌍 Менеджер серверов (Блокировка лагающих дата-центров)**
    Попадаете на сервер с высоким пингом или плохим качеством? Скрипт автоматически определяет ваш текущий сервер и позволяет добавить его в "чёрный список". При следующем запуске игры скрипт заблокирует подключение к нежелательному серверу, заставляя Boosteroid перенаправить вас на другой дата-центр.
*   **🎬 Выбор видеокодека и Лимит битрейта**
    Принудительно выбирайте желаемый кодек видеопотока (H.265/HEVC, H.264 или AV1) и устанавливайте максимальный битрейт через манипуляцию SDP для улучшения стабильности на слабых сетях.
*   **🚀 Пропуск экрана выхода**
    Автоматически пропускает экран оценки и отзыва после игры, сразу возвращая вас на главную страницу.
*   **🎨 Удобный интерфейс (UI)**
    Настройки вызываются по клику на иконку шестеренки и встроены прямо в страницу Boosteroid с использованием технологии Shadow DOM (что гарантирует отсутствие конфликтов с дизайном самого сайта).
*   **🌐 Мультиязычность**
    Поддержка английского, русского, украинского и испанского языков с автоматическим определением языка системы.

## ⚙️ Как установить

Установка занимает всего пару минут:

1. **Установите расширение Tampermonkey** для вашего браузера (поддерживаются Chrome, Firefox, Edge, Safari, Opera):
   * [Tampermonkey для Chrome](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
   * [Tampermonkey для Firefox](https://addons.mozilla.org/ru/firefox/addon/tampermonkey/)
   * [Tampermonkey для Edge](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd)
   
2. **Установите сам скрипт:**
   * Откройте расширение Tampermonkey и выберите **"Создать новый скрипт"** (Create a new script).
   * Удалите всё содержимое в открывшемся окне.
   * Скопируйте весь код из файла `boosteroid_tweaks.user.js` в репозитории и вставьте его в редактор Tampermonkey.
   * Нажмите `Ctrl+S` (или Файл -> Сохранить), чтобы сохранить скрипт.

3. **Готово!**
   * Перейдите на сайт [cloud.boosteroid.com](https://cloud.boosteroid.com/).
   * В левом нижнем углу экрана (или на странице запуска) появится иконка **Boosteroid Tweaks** ⚙️. Нажмите на неё для настройки!

## 📝 Как пользоваться менеджером серверов

1. Запустите любую игру.
2. Откройте панель **Boosteroid Tweaks** (кнопка ⚙️).
3. В разделе **"Последний сервер"** вы увидите адрес дата-центра, к которому вы подключились (например, `gw-par.boosteroid.com`).
4. Если сервер работает плохо (большой пинг/потери пакетов), нажмите кнопку **"Заблокировать этот сервер"**.
5. Завершите сессию и запустите игру заново — скрипт заблокирует подключение к этому адресу, и Boosteroid подберет для вас другой дата-центр.

## 👨‍💻 Для разработчиков

Скрипт использует передовые методы инжекта:
* Переопределение конструктора `window.WebSocket` для отслеживания и фильтрации сетевого обмена с серверами Boosteroid (обход AFK и блокировка).
* Использование WebRTC API (`RTCPeerConnection`) для сбора нативной телеметрии без задержек.
